Temperature Converter

📌 About the Project

The Temperature Converter is a web-based application developed as part of the Oasis Infobyte Web Development and Designing Internship. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

✨ Features

- Converts Celsius to Fahrenheit and Kelvin.
- Converts Fahrenheit to Celsius and Kelvin.
- Converts Kelvin to Celsius and Fahrenheit.
- Simple and easy-to-use interface.
- Displays converted temperature values instantly, if JavaScript conversion is implemented.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🧮 Conversion Formulas

- Celsius to Fahrenheit: °F = (°C × 9/5) + 32
- Fahrenheit to Celsius: °C = (°F − 32) × 5/9
- Celsius to Kelvin: K = °C + 273.15
- Kelvin to Celsius: °C = K − 273.15

🚀 Getting Started

1. Clone or download this repository.
2. Open the Temperature Converter project folder.
3. Open "Index2.html" in your web browser.
4. Enter a temperature and select the appropriate conversion options.
