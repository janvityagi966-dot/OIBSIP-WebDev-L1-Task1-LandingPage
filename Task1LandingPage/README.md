**Landing Page – Oasis Infobyte Internship Task 1

**📌 About the Project

This project is a responsive landing page developed as part of Task 1 of the Oasis Infobyte Web Development and Designing Internship.

The main objective of this project is to learn and practice the fundamentals of frontend web development by creating an attractive and well-structured webpage using HTML and CSS.

**✨ Features

- Simple and attractive user interface
- Navigation bar with multiple links
- Hero section with a headline and call-to-action button
- Multiple content sections
- Student feedback section
- Footer section
- Responsive layout for different screen sizes

**🛠️ Technologies Used

- HTML5 – Used to structure the webpage.
- CSS3 – Used to style the page, manage layouts, and improve its appearance.
- Flexbox and CSS Grid – Used for arranging webpage elements, where implemented.

**📂 Project Structure

OIBSIP-WebDev-L1-Task1-LandingPage/
├── Index.html

└── README.md

🚀 How to Run the Project

1. Clone the repository:
   
   git clone https://github.com/janvityagi966-dot/OIBSIP-WebDev-L1-Task1-LandingPage.git

2. Open the project folder in Visual Studio Code.

3. Open "Index.html" in your browser, or use the Live Server extension.

**🎯 Learning Outcomes

- Understanding the structure of HTML documents.
- Learning CSS styling and typography.
- Understanding the difference between margin, padding, and border.
- Practicing Flexbox and responsive layouts.
- Creating sections and navigation links.
- Using Git and GitHub to manage and publish a project.
