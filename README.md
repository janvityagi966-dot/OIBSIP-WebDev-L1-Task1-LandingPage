3. Temperature Converter

Description:

A web-based temperature conversion application that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin, depending on the conversions implemented in the project.

The project demonstrates the use of user input, temperature conversion formulas, and JavaScript logic.

Features:

- Temperature input field.
- Conversion between temperature units.
- Display of converted results.
- Simple and user-friendly interface.
- Input validation, where implemented.

Technologies Used:

- HTML5
- CSS3
- JavaScript

Temperature Conversion Formulas:

- Celsius to Fahrenheit: °F = (°C × 9/5) + 32
- Fahrenheit to Celsius: °C = (°F − 32) × 5/9
- Celsius to Kelvin: K = °C + 273.15
- Kelvin to Celsius: °C = K − 273.15
- Fahrenheit to Kelvin: K = (°F − 32) × 5/9 + 273.15
- Kelvin to Fahrenheit: °F = (K − 273.15) × 9/5 + 32

Learning Outcomes:

- Applying JavaScript to perform calculations.
- Handling user input and displaying results.
- Understanding basic conditional logic.
- Connecting interface elements with application functionality.
